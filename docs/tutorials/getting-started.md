# Get started

Install a [Rust toolchain](https://rustup.rs/), clone the repository and run:

```sh
git clone https://github.com/7ucardie/RustDU.git
cd RustDU
cargo run --release
```

Choose a folder to scan, or drop one on the window. Expand folders in Explorer to see where space is used.
Select an item to see its details in the Inspector. Use the column headers to sort the tree.

To start with a particular folder, run `cargo run --release -- /path/to/folder`.
